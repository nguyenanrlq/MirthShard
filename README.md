MirthShard optimizes real-time data exchange via cloud-based, message-queued architectures, utilizing server-gateway protocols for efficient data processing.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/MirthShard.git`
2. `cd MirthShard`
3. Install in editable mode: `pip install -e .`

## Configuration

MirthShard is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
